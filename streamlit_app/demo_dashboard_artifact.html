Why multi-agent

Same labels · different operations

Both pipelines produce identical labels on all 567 routes — the ML verdict is the same. What the graph adds is operational, the properties a flat script does not provide without a rewrite.

Classical pipeline sequential

Same 17/40/510 anomaly split, same 9 CRITICAL
Seven inlined steps, readable top-to-bottom
Ends at a ranked CSV — no narration
Runs once — no self-correction
Static perimeter, coupled failure surface

Multi-agent graph LangGraph

LLM narration per HIGH/MEDIUM route, faithful by construction
Verifier feedback cycle — refits IF at contamination 0.03
Per-agent failure isolation — partial state surfaced to the UI
Dynamic perimeter — analyst restricts the run at runtime
Pluggable backend — Claude, local model, or none
